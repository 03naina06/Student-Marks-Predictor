Student Performance Predictor :-

📌 About the Project

This project is a simple web-based application that helps predict a student’s marks based on their daily habits and academic performance.

The main idea behind this project is that a student’s result does not depend only on study hours. Factors like attendance, sleep, assignment completion, and even screen time also play an important role.

Along with predicting marks, the system also gives suggestions and a detailed analysis so that students can understand where they need to improve.

---

🎯 Purpose

The purpose of this project is to create a basic system that can analyze student performance in an easy and practical way. It also helps in understanding how simple prediction systems work, which is an important concept in Machine Learning.

---

🧠 What the Project Does

The user enters some details like:

- Study hours
- Attendance
- Assignment completion
- Previous marks
- Sleep hours
- Screen time

Based on these inputs, the system:

- Predicts marks
- Shows the result in a graph
- Tells if performance is improving or not
- Gives suggestions for improvement
- Provides a detailed report

---

✨ Features

- Prediction: Calculates marks based on given inputs
- Graph: Shows performance over multiple attempts
- Trend: Displays improving or declining performance
- Suggestions: Gives quick tips to improve
- Detailed Analysis: Shows strengths, weaknesses, and recommendations

---

🛠️ Technologies Used

---

⚙️ How It Works

The system uses a simple formula to calculate marks:

Marks =
(0.25 × Previous Marks) +
(5 × Study Hours) +
(0.25 × Attendance) +
(0.15 × Assignments) +
(2 × Sleep Hours) -
(2 × Screen Time)

The result is always kept between 0 and 100.

---

🚀 How to Use

1. Open the project in your browser
2. Enter all the required values
3. Click on Predict Marks
4. View the result, graph, and suggestions
5. Click Get Detailed Analysis for more insights
